# Roblox Brainrot AI Game

## Overview
This repository contains the source code for **Roblox Brainrot**, an AI‑driven Roblox game that challenges players with ever‑changing puzzles and obstacles generated in real‑time by a language model. The game showcases how large language models can be integrated into Roblox Studio to create dynamic, emergent gameplay experiences.

## Features
- **Procedural Level Generation**: Levels are generated on‑the‑fly using a custom AI prompt that designs platform layouts, enemy placements, and collectible items.
- **Adaptive Difficulty**: The AI monitors player performance and adjusts the difficulty curve to keep the experience engaging.
- **Narrative Integration**: An AI‑generated storyline evolves based on player choices, providing a unique narrative for each playthrough.
- **Roblox Studio Compatibility**: Built with TypeScript (via `roblox-ts`) and runs on Roblox's latest Studio version.

## Getting Started
1. **Clone the repository**
   ```bash
   git clone https://github.com/<owner>/<repo>.git
   cd <repo>
   ```
2. **Install dependencies**
   ```bash
   npm install -g roblox-ts
   npm install
   ```
3. **Open in Roblox Studio**
   - Open `main.rbxlx` (generated by the build script) in Roblox Studio.
   - Press **Play** to start the AI‑driven experience.

## Build & Run
The entry point for the grader is `main.ts`. It sets up the AI service, registers the game logic, and starts the server.
```bash
npm run build   # Compiles TypeScript to Lua
node main.ts    # Starts the AI controller (headless for CI)
```
